A program that writes one original line (120 characters) roasting the gadget
used every day — the phone charger that only works at one exact angle — to
`/output/entry.txt`.

Entry for the [make.fun bounty](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610)
"One-Line Roast: The Gadget You Use Every Day" ($5 USDC, escrowed).

## Run

```sh
node main.ts
cat /output/entry.txt
```

## The line

> My phone charger only works at one exact angle, so every night I do the same sacred ritual: bend, balance, pray, repeat.
